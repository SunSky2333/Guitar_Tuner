## 4. 安装步骤

### 4.1 安装 Android Studio

1. 从 [developer.android.com/studio](https://developer.android.com/studio) 下载最新稳定版安装包。
2. 安装向导中勾选组件（如向导未自动勾选，装完后在 SDK Manager 补装）：
   - Android SDK
   - Android SDK Platform-Tools
   - Android Emulator（可选）
3. 首次启动后自动下载 SDK；如下载慢，见 §5 镜像配置。

### 4.2 配置 SDK 组件（SDK Manager）

在 Studio 的 `Settings → Languages & Frameworks → Android SDK` 中确认：

- SDK Platforms：勾选 **android-34 或 android-35**
- SDK Tools：勾选 **Android SDK Build-Tools**、**Android SDK Platform-Tools**、**Emulator**（可选）

### 4.3 准备真机（M2 前完成）

1. 手机：`设置 → 关于手机 → 连点版本号 7 次` 开启开发者模式。
2. `设置 → 开发者选项 → 开启 USB 调试`。
3. USB 连接电脑，首次连接弹窗点「允许 USB 调试」。
4. 验证：命令行执行 `adb devices`，能看到设备序列号即成功。

### 4.4 环境变量（2026-08-13 已配置 ✅）

- `JAVA_HOME` → `D:\Java\jdk-21\jdk-21.0.10`（已设置）
- `ANDROID_HOME` → `C:\Android\Sdk`（已设置）
- `ANDROID_SDK_ROOT` → `C:\Android\Sdk`（已设置，部分工具链读取该变量）
- 生效说明：`setx` 写入的是用户级持久变量，**新开的终端/进程生效**；当前已打开的终端需重新打开或手动 `export`。

## 5. 国内网络加速配置（强烈建议）

Gradle 发行版与 AGP 依赖默认从国外服务器下载，国内首次构建可能耗时半小时以上。建议项目脚手架创建后立即配置：

### 5.1 Gradle 发行版镜像

修改 `gradle/wrapper/gradle-wrapper.properties`：

```properties
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.x-bin.zip
```

### 5.2 Maven 依赖镜像（阿里云）

在根 `settings.gradle.kts` 的 `repositories` 中，将镜像置于 `google()` / `mavenCentral()` 之前：

```kotlin
pluginManagement {
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        maven("https://maven.aliyun.com/repository/public")
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/public")
        google()
        mavenCentral()
    }
}
```

## 7. 常见问题速查

| 问题                              | 处理                                   |
| ------------------------------- | ------------------------------------ |
| 首次构建长时间卡在下载依赖                   | 检查 §5 镜像配置是否生效                        |
| `adb devices` 识别不到真机               | 换数据线 / 装厂商 USB 驱动 / 手机弹窗允许 USB 调试      |
| 模拟器上收不到音频输入                     | 属正常现象，音频采集必须真机（M2/M4 换真机验证）          |
| Gradle 版本与 AGP 不匹配               | 以 Wrapper 指定版本为准，AGP 与 Gradle 兼容表见官方文档 |
| 编译报 `JAVA_HOME` 相关错误              | 按 §4.4 设置 JAVA_HOME 后重启终端              |
