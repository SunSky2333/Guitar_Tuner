# 吉他调音器 · M1 验收报告（核心 DSP + 单元测试）

> 日期：2026-08-13 · 对应文档：《吉他调音器开发文档.md》§11/§12.1  
> 验收结论：**PASS** — 6 套调弦 30 个音全部通过，最大误差 0.07 音分（≤ 1 音分要求）

---

## 1. 交付物

| 文件 | 说明 |
| ---- | ---- |
| `dsp/src/main/kotlin/com/example/guitartuner/dsp/PitchDetector.kt` | YIN 基频检测器（差分函数 → 累积均值归一化 → 阈值检测 → 抛物线插值） |
| `dsp/src/main/kotlin/com/example/guitartuner/music/NoteMapper.kt` | 频率 → 音名/八度 + 音分偏差计算 |
| `dsp/src/main/kotlin/com/example/guitartuner/music/Tunings.kt` | 6 套调弦定义（吉他标准/drop-D/drop-C，尤克里里标准/降半音/降全音） |
| `dsp/src/test/kotlin/com/example/guitartuner/PitchDetectorTest.kt` | JUnit5 验收测试（5 个用例） |
| `dsp/src/test/kotlin/com/example/guitartuner/VerifyReport.kt` | 逐音误差明细报告（`./gradlew :dsp:verifyReport`） |

**工程形态**：纯 Kotlin JVM 模块 `dsp/`（Kotlin 2.0.21，JDK 21 toolchain），不依赖 Android SDK，M2 起由 `app/` 模块直接依赖复用。
