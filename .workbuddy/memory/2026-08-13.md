- 决策背景：端到端延迟预算 = 帧积累 46ms（2048 点，YIN 硬成本，Oboe 无法压缩）+ 系统采集缓冲 ~30ms（Oboe 可压至 ~12ms）+ DSP ~4ms + UI 16ms ≈ 96ms（当前）vs ~76ms（Oboe）；收益 ~20ms 但对调音感知无意义（容忍 ~100-150ms）。Oboe 代价：NDK/JNI、PitchDetector C++ 化、麦克风 input 低延迟依赖设备 HAL 不保证。
